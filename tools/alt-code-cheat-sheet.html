Alt Code Cheat Sheet

Hold Alt, type the number on the numeric keypad, let go. The leading zero picks which character set Windows reads the number from, so the same character often has two codes.

Alt+0176 →°Windows set
Alt+248 →°DOS set
  1. Turn Num Lock on.
  2. Hold the left Alt key.
  3. Type the digits on the numeric keypad. The top row does not work.
  4. Release Alt. The character appears.
Keyboard language when you type the code

Everyday picks

Click any key to copy the character.

Windows set Alt + 0NNN

DOS set Alt + NNN

Nothing matches. Try a different word, or switch the keyboard language above.

The zero changes the answer

Alt + 0176 is ° but Alt + 176 is ░. Codes 32 to 126 are the plain keyboard characters and come out the same either way.

Wrong character?

Check the language indicator in the taskbar. The code is read from the character set of the keyboard language that is active while you hold Alt, so the same code gives é in English and י in Hebrew.

No numeric keypad

Press Win + . for the symbol panel, or run charmap. In Word, type the hex code and press Alt + X: 2014 becomes an em dash.

Numbers above 255

Most programs wrap them around, so Alt + 257 types the same thing as Alt + 1. Word and WordPad read them as Unicode instead.
